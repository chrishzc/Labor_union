# 欄位權威性與計算邏輯盤點

## 文件狀態

- 狀態：討論與裁決用工作清冊；不是 SSOT，不代表 CP-1、Task 或實作核准。
- 範圍：`db/schema.sql` 與 `db/schema_parts/*.sql` 中可辨識的資料表、欄位及外鍵。
- 用法：先建立完整骨架，再逐欄確認權威來源、公式、命令、狀態機與凍結邊界。
- 限制：初版只記錄 schema 宣告；live writer、API 與 UI 漂移會在逐欄核對時補入。

## 欄位分類

| 分類 | 定義 |
|---|---|
| 來源事實 | 由人員、外部事件或正式命令提供，不能由其他投影反推 |
| 衍生投影 | 可由更基礎事實重算，不具獨立業務權威性 |
| 不可變快照 | 跨越財務或稽核邊界後保存當時計算依據 |
| 工作流狀態 | 表示命令、人工審核或處理流程的階段 |
| 領域狀態 | Aggregate 的正式生命週期結果 |
| 稽核／關聯 | 保存版本、操作者、原因、冪等與 lineage |
| 待分類 | 尚未逐項裁決 |

## 已確認的全域帳務核銷規則

- 適用範圍：訂金、頭款、尾款、共用財務調整、補助退還、月嫂一般應付、樓層費、月嫂調整及其他正式應收／應付義務。
- 原始銀行流水不論金額是否正確，均先保存在 `finance_import_rows`；此層是外部金流事實，不等於已核銷的正式交易。
- 核銷 Preview 可同時選取一筆或多筆原始流水及一筆或多筆同方向義務，但 Apply 前必須同時滿足：
  - 每一筆所選金流均被完整分配，未分配差額為 0。
  - 每一筆所選應收／應付義務套用後餘額均恰好為 0。
  - 不得跨越業務上禁止互抵的義務邊界；訂金、頭款、尾款仍各自獨立核銷。
- 任一條件不成立即整批禁止建立正式交易與分配；原始流水留在匯入層並觸發財務異常／人工處理。正式帳本不保存部分核銷或未分配中間狀態。
- 多筆原始流水可在同一次核銷 Apply 中共同結清一筆義務；一筆原始流水也可透過 M:N 分配同時結清多筆允許合併處理的義務。Apply 必須是全有或全無的原子寫入。
- 同一次原子核銷的所有 `finance_import_rows` 共用同一個 `reconciliation_reference`，作為核銷 Apply 的共同識別與冪等關聯；不另建核銷批次表。此 reference 不參與金額計算，正式交易仍各自以 `finance_import_row_id` 指回原始流水。
- 月嫂薪資以「同一月嫂、同一薪資月份、同一有效 revision 的整張 `staff_monthly_settlements`」為唯一正式核銷單位。月結 `total_payable` 是該月所有訂單／assignment 明細應付加總；明細只說明月結金額的來源與構成，不是各自獨立的銀行核銷義務。只有同次 Apply 所選成功出款的方向淨額恰好等於整張月結 `total_payable`，才可原子建立正式匯款並將月結標為 `paid`。不要求把匯款再分配回每筆訂單、assignment 或薪資元件，也不得新增 `partially_paid` 月結。
- 基本月嫂薪資月份不得由 caller、銀行出款日期或 `staff_payments` 重複欄位指定。唯一血緣為：訂單完成日與客戶付款類型 → 訂單層正式 `staff_payment_due_date` → `month_start(staff_payment_due_date)` → `staff_monthly_settlements.settlement_month`。客戶有服務費應付時為訂單完成後次月 15 日；客戶服務費為 0 且政府全額補助時為完成後次次月 15 日。同一月嫂所有訂單應付月份相同的 assignment 必須進入同一月份月結。`staff_payments.due_date` 標記長期考慮移除。
- 已完整支付的月結永不重開、覆寫或建立取代它的歷史 revision。之後才核准的正負財務調整，應作為新的月結義務進入該月嫂下一個尚未 finalized 的月結月份；原已付月結及其明細保持不變。

## 已確認的跨表原則

- `case_staff_assignments.actual_hours`：衍生投影／可重建快取；權威來源為 assignment-owned 正式工作日。
- `orders.actual_end_date`：衍生投影；由全案有效 assignment-owned 正式工作日最大日期推算。
- 未跨越付款／月結邊界的排班修改：取消目前有效 assignments，依完整 Preview 建立新 assignments 與正式服務日。
- 跨越付款／月結邊界後：保留原 assignment 與不可變財務快照，改走調整／沖正。
