# Table: finance_import_reprocess_runs

## 1. 核心定位與職責
- 領域分類：07_財務匯入與警示
- 類型：事件日誌 (Event Log)
- 現況定位：紀錄管理員對已完成匯入批次中，仍為 `non_business_review + pending` 的 canonical rows 執行重分類與再次 dispatch 的完成結果。dry run 會 rollback，不建立本表紀錄。
- Schema：`db/schema_parts/61_finance_import_reprocessing.sql`
- Writer：`services/finance_import_reprocessing.py::reprocess_finance_import_batch`
- 子表關係：`finance_import_reclassification_events.run_id`
- 第一遍（live 現況）：已補齊 16 個 Schema 欄位。
- 第二遍（衍生判定）：已完成。
- 根事實展開：已完成。
