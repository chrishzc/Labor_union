# Table: finance_import_reprocess_runs

## 1. 核心定位與職責
- 領域分類：07_財務匯入與警示
- 類型：事件日誌 (Event Log)
- 現況定位：紀錄管理員對已完成匯入批次中，仍為 `non_business_review + pending` 的 canonical rows 執行 typed Preview/Apply 後的完成結果。Apply 必須帶入 preview fingerprint、預期 batch version、idempotency key 與操作理由；dry run 不建立本表紀錄。
- Schema：`db/schema_parts/61_finance_import_reprocessing.sql`
- Writer：`subsystems/finance_import/historical_reprocess_workflow.py::HistoricalReprocessWorkflow` 透過 `infrastructure/mysql/historical_reprocess_repository.py::MySqlHistoricalReprocessRepository.append_reprocess_run`。舊 `services/finance_import_reprocessing.py` 已退役；`subsystems/finance_import/reprocessing.py` 僅保留 rollback-only 診斷，不得 Apply。
- 關聯稽核：逐列分類決策寫入 `finance_import_classification_events`；命令重播收據寫入 `finance_import_historical_reprocess_receipts`；人工歸屬證據寫入 `historical_owner_selection_events`。舊 `finance_import_reclassification_events` 已退役，非本表子表。
- 第一遍（live 現況）：已補齊 16 個 Schema 欄位。
- 第二遍（衍生判定）：已完成。
- 根事實展開：已完成。
