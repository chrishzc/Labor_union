## Acceptance 與 effect ceiling

1. 九表以案件編號關聯且保持各自 grain，包含取消／沖銷／被替換明細。
2. 全部符合篩選的案件被匯出；既有匯出不退役。
3. 登入授權、固定 SQL 白名單、原生金額／日期、案件文字識別碼與零公式注入。
4. 不輸出真實帳號、身分證、電話、地址或原始內容。
5. Query 零寫入、無 commit、無 provider effect。

最低驗證：focused backend workbook／repository／route tests、React download／filter tests、TypeScript 與 architecture closure。
必要時以本機 DB 唯讀 SQL 驗證投影欄位；不匯出實際個資作測試附件。
Safe stop：必要驗收通過即停止；未授權移除其他表或增加通用資料庫瀏覽器。
