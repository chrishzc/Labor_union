### 重構方式

Repository 改成只提供：

- `load`
- `load_for_update`
- `append`
- `save`
- `compare_and_swap`
- `save_receipt`
- `append_outbox`

commit／rollback 由外層 application composition 或 UoW 負責。

禁止把 commit 從 repository 移到 FastAPI route；必須移到真正的 outer UoW owner。

### 特別案例：HCM claim

目前 `claim()` 與 `save_receipt()` 分別 commit，必須判斷：

- claim 是否應與整個 command 同交易；
- 或是否為合法 durable command-claim transaction。

若為 durable claim，必須具有：

- 明確 command state machine
- crash recovery
- resume contract
- outcome query
- 不把 claim 冒充 business success

不能只因需要避免重複就保留中途 commit。

### 驗收

- production repository 不再自行決定業務 commit。
- 每個 mutation 只有一個 outer UoW owner。
- rollback 不留下 receipt／outbox／projection partial state。
- replay、crash-resume、stale、exception paths 均有測試。
- 新增靜態測試禁止 repository-owned commit，對允許清單 fail closed。
