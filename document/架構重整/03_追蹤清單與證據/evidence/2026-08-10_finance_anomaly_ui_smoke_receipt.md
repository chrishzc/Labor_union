# 2026-08-10 帳務異常中心與管理端 UI Smoke Receipt

## 範圍與方法

- 環境：本機 `http://127.0.0.1:8501/`、既有 UI 驗證資料與已啟動 API。
- 方法：以瀏覽器實際切換頁面／工作區，等待目標 heading、表單或資料區塊可見後，再額外
  等待 UI 穩定；檢查可見文字是否含載入、讀取、請求或處理失敗／錯誤、Traceback、Exception。
- 本輪沒有點擊任何 Preview Apply、正式入帳、下載或資料修改按鈕；這是 UI 載入與導向 smoke
  test，不是正式帳務 mutation 驗收。
- 時間為同一本機工作階段的 warm-load 觀測值，包含 Streamlit rerun 與可見資料完成，不能
  作為 production SLO。

2. 待人工處理批次顯示筆數與「前往帳務異常中心」，不再提供任意選第一筆並開啟修正的入口。
