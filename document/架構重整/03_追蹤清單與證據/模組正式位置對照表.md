# 模組正式位置對照表

建立日期：2026-08-07（隨封存的 [`30_Finance_Import_Legacy_Import_Path_Repair_Receipt.md`](../04_已完成與上線封存/receipts/30_Finance_Import_Legacy_Import_Path_Repair_Receipt.md) 一併整理）

## 用途

「架構重整」分支合併後，大量 `services/*.py` 舊模組被搬到
`domains/*`、`subsystems/*`、`infrastructure/mysql/mysql_adapter.py`，但很多
caller 的 import 路徑沒有跟著更新。過去要判斷「這個函式現在正式住在哪」，
只能逐一 `grep -rn "^def <name>"` 全庫搜尋、再讀對應 Decision Package 確認退役
狀態，非常耗時且容易漏。本表把已經查證過的對照結果集中記錄，供之後任何人
（或 agent）直接查表，不用重新地毯式搜尋。

**本表只記錄「舊路徑 → 現在正式路徑」的事實對照，不構成規格；若與
`01_規格基線/` 或 `02_決策與退役執行記錄/` 的文字衝突，一律以那兩層為準，
本表需同步修正。**

## 如何維護本表

新增一列前，先用以下指令確認目標函式真的存在於建議路徑，不採信未經驗證的
路徑猜測：

```bash
grep -rn "^def <function_name>" --include="*.py" .
```

發現 caller 仍指向已不存在的 `services.*` 路徑時，可用這個指令抓出全部：

```bash
grep -rhoE "from services\.[a-zA-Z0-9_]+ import|import services\.[a-zA-Z0-9_]+" \
  --include="*.py" . | sed -E 's/from services\.([a-zA-Z0-9_]+).*/\1/; s/import services\.([a-zA-Z0-9_]+)/\1/' \
  | sort -u > /tmp/referenced.txt
ls services/*.py | xargs -n1 basename | sed 's/\.py$//' | sort -u > /tmp/existing.txt
comm -23 /tmp/referenced.txt /tmp/existing.txt   # 有引用但不存在的模組
```
