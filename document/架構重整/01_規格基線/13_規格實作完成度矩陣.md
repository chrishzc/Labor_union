## 1. 狀態定義

| 狀態 | 定義 |
|---|---|
| `proven` | production 入口、正式 owner、持久化與相應分層測試均有可重現證據 |
| `partial` | 部分層級已完成，但正式入口、交易、持久化或指定層級驗收仍缺一項以上 |
| `missing` | 規格已確認，但尚無符合新架構的 production capability |
| `conflict` | live 實作繞過或違反已確認 SSOT／交易邊界 |
| `decision-required` | 現有規格不足以唯一決定 owner 或 public contract，需人工裁決 |
| `external-gate` | 必須在專用部署或全隔離環境取得證據，不能以 unit test 推定 |
| `retired` | 經人工決策停止作為產品能力或 release gate；僅保留歷史追溯，不得重新以舊驗收要求阻擋發布 |
