# 正式規格索引與裁決總表

## 1. 權威順序與文件治理原則

本文件為全專案唯一規格目錄總表，對應 [00_規格書撰寫與生命週期規範.md](../00_規格書撰寫與生命週期規範.md) 的「現行唯一真相（Living Current Truth）」原則，只保存現行有效架構版圖、領域唯一真相（SSOT）索引與全域不可違反裁決。

- **真相權威鏈**：
  1. 最新人工明確書面指示；
  2. 本目錄各現行 owner 正式規格；
  3. 程式碼、測試、資料庫現況、附件與 Git 歷史僅作現況或歷史證據；現況若與規格不符，一概記為 `live-drift`，禁止反向以現況或測試預設蓋過規格。
- **唯一擁有權原則**：同一業務規則、金額公式、狀態機與資料契約僅存在於單一 owner 規格中，其他文件一律以連結指向，禁止跨檔抄寫或保留時序性補丁記錄。

## 4. 關鍵全域不變量與跨模組邊界

1. **三段職責分離與單一提交所有者（UoW）**：`Query` 嚴格唯讀、`Preview` 零資料庫寫入、`Apply` 強制於唯一 outer Unit of Work 內重新檢視新鮮根事實後原子提交業務狀態、receipt 與 post-commit outbox。外部 provider（如 LINE Push、檔案封存）失敗固定不得回滾核心業務交易。
2. **內部平權存取控制（`CON-AUTH-001`）**：所有已認證且啟用之內部管理員帳號具有完全一致的業務功能權限；僅唯一啟用中 `root` 帳號額外擁有 Access Control 帳號中心管理權（詳見 [External Integration 與 Access Control](17_External_Integration_LINE_Access正式規格.md)）。
3. **帳務與補助邊界（`CON-SET-001/002`、`CON-SUB-001`、`CON-REF-001/002`）**：
   - 不建立人工月結 aggregate；月嫂給付依有效 assignment 產生單筆不可變應付義務，同日同人僅於查詢與匯出層匯聚，不拆成補助薪資／自費薪資。
   - **政府溢付款退回機制已永久退役**（僅保留合法抵扣 `offset` 與人工核銷追蹤）；退款義務清償（Refund）與收款無效化重開應收（Reversal）嚴格分命令執行。
   - 補助上限依正式確認政策：**一般市民 40 小時**、**補助市民／社福 120 小時**、**原住民（帳務參數設定，預設 80 小時）**；補助市民或原住民實際核定時數 `H <= 有效 L` 時自動適用免自備款（`B=0, S=T`）。詳細案款分配與補助流向以三方案模型為準。
4. **待審儲存實體隔離（`CON-REG-STORAGE/RETENTION`）**：產婦問卷與非市民線上新申請於工會核准前一律存放專用持久化 Redis 7（AOF 同步、`noeviction`、**14 天到期自動失效清理**），收件端無任何 MySQL 連線憑證；核准成功始寫入 MySQL 並立即依回執清除待審鍵。
5. **非同步作業等價性與可驗證性（`CON-JOB-001`）**：Durable Job 等價識別固定為 `type + version + canonical JSON payload + immutable actor`，`key` 限小寫 ASCII，並具崩潰自動接管恢復能力（詳見 [Background Job 與部署治理](18_Global_Deployment與治理正式規格.md)）。
