# 資料庫、資料處理與參考模板目錄索引

## 目錄定位

本目錄為系統資料庫維運、匯入格式驗證、測試資料規則，以及管理端輸出表格需求模板的統一參考資源庫。
原 `document/管理端UI/` 之表格模板已於 2026-10-29 完整合併入本目錄下的 `表格需求模板/` 子目錄。

**權威約束提醒**：
1. 本目錄檔案屬於測試 fixture、驗證規劃草案或輸出形狀參考，**不得覆蓋 `document/架構重整/01_規格基線/` 之正式規格**。
2. 非 Markdown 核心附件之 Git Blob SHA 與分類由 `document/文件整併工作區/08_非Markdown附件索引.md` 統一治理。

### 三、管理端與業務報表表格需求模板（`表格需求模板/`）
整合自原 `document/管理端UI/`，作為報表輸出形狀與欄位建議之參考模板：
- `所需表格.xlsx`：包含合約與業務資訊工作表，由合約渲染測試直接校驗結構。
- `應付帳款.xlsx`：Accounts Payable Export 格式與輸出形狀參考。
- `週報.xlsx`：營運週報 3 個業務分頁（受理總表、補助統計、服務中與工時）之需求來源。
- `核銷含印領清冊.xlsx`：政府補助核銷清冊之報表欄位模板。
- `服務人員契約.xlsx`：工作人員契約書文字與格式參考。
- `資料庫原始資料瀏覽_頁面欄位開放權限建議表.xlsx`：管理端權限與欄位遮罩盤點參考表。
